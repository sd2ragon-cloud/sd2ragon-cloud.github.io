개인정보처리방침

shorts-uploader · 시행일 2026-11-09

1. 대상

이 방침은 YouTube 채널 「빌딩탐정」의 운영자가 사용하는 개인용 업로드 도구 shorts-uploader(이하 "도구")에 적용됩니다. 도구는 운영자 본인만 사용하며 다른 사람에게 배포되거나 제공되지 않습니다.

2. 사용하는 Google 사용자 데이터

  • youtube.upload: 운영자 본인 채널에 동영상을 업로드합니다.
  • youtube.readonly: 업로드 전, 로그인한 계정이 빌딩탐정 채널인지 확인하기 위해 본인 채널의 ID와 이름만 조회합니다.

다른 YouTube 사용자의 데이터는 조회, 수집, 저장하지 않습니다.

3. 저장 및 보관

OAuth 인증 토큰은 운영자 PC에만 저장되며 외부 서버로 전송되지 않습니다. 업로드한 동영상의 ID와 주소만 운영 기록으로 PC에 보관합니다.

4. 제3자 제공

Google 사용자 데이터를 판매하거나 제3자에게 제공하지 않습니다. 도구의 Google API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 권한 철회

언제든지 Google 계정 권한 페이지에서 도구의 접근 권한을 해제할 수 있으며, 해제 시 PC에 저장된 토큰은 더 이상 사용할 수 없습니다.

6. 문의

GitHub 문의 게시판(Issues) 또는 YouTube 채널 「빌딩탐정」 댓글

Privacy Policy (English summary)

shorts-uploader is a private, single-user tool used only by the owner of the YouTube channel "빌딩탐정". It uses the youtube.upload scope to upload videos to the owner's own channel and youtube.readonly only to confirm the authenticated channel's ID and title. It does not access, collect or store data of any other user. OAuth tokens are stored only on the owner's computer and never transmitted elsewhere. Google user data is not sold or shared. Use of Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
